# 🌐 HTML5 and CSS3 Course

This repository documents my **studies, exercises, and practical projects** developed during the **HTML5 and CSS3** course taught by **Gustavo Guanabara**, from the [**Curso em Vídeo**](https://www.cursoemvideo.com/) platform.

The course is composed of **5 modules**, each with approximately **40 hours of content**, and **a final assessment at the end of every module** to validate the acquired knowledge.

This repository reflects my learning journey and technical progress throughout the course.

## Course Structure and Topics

### Module 1
- How the internet works (domains, hosting, and web infrastructure)
- Differences between HTML, CSS, and JavaScript
- Front-end, back-end, and full-stack concepts
- HTML5 fundamentals and document structure
- Text elements, headings, paragraphs, symbols, and emojis
- Proper use of images, formats, optimization, and favicons
- Semantic HTML and correct text formatting
- Lists, links, anchors, and downloads
- Responsive media: images, audio, and video
- Inline, internal, and external CSS

### Module 2
- Color theory, psychology, and color harmony
- CSS color representation, gradients, and palettes
- Typography fundamentals and font management
- Google Fonts and external fonts
- CSS selectors: `id`, `class`, pseudo-classes, and pseudo-elements
- Box Model
- Grouping tags, borders, shadows, and rounded corners
- Building a complete project from scratch
- CSS variables
- Responsive layouts and mobile adaptation
- Responsive videos and structured layouts

### Module 3
- Introduction to Git and GitHub
- Repository creation, management, and cloning
- Hosting websites with GitHub Pages
- Site maintenance and collaboration features
- Background images and CSS background properties
- Vertical alignment techniques
- Parallax effects
- Advanced HTML tables
- Large tables, captions, scopes, zebra effects, and responsive tables

### Module 4
- Proper and secure use of iframes
- Page layout and content positioning
- Social media buttons and pages
- HTML5 forms and accessibility
- Input types, validation, and browser compatibility
- GET and POST methods
- Media Queries fundamentals
- Mobile First
- Responsive navigation menus
- Responsive login screen project

### Module 5
- Flexbox fundamentals: axes, alignment, flow, and sizing
- Responsive menus with Flexbox
- Flexible layouts using only Flexbox
- CSS Grid fundamentals and anatomy
- Grid container and item propertiesd
- Responsive design and layout structuring
- Sticky header, smooth scrolling, and dark mode

## Repository Purpose

- Build a strong foundation in HTML5 and CSS3  
- Practice real-world web layout techniques  
- Develop responsive and well-structured websites  
- Prepare for JavaScript and full-stack development
